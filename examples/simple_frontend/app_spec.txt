<project_specification>

<project_name>TaskFlow - Modern Task Management App</project_name>

<overview>
A modern, responsive task management single-page application built with React and TypeScript.
Features include task creation, categorization, due dates, priority levels, and drag-and-drop
organization. The app uses local storage for persistence with optional cloud sync capabilities.
</overview>

<user_personas>
1. Individual User - Personal task management
2. Small Team Lead - Coordinating team tasks
3. Freelancer - Managing multiple project tasks
</user_personas>

<technology_stack>
<languages>
- TypeScript 5.x
</languages>

<frontend>
- React 18.x with hooks
- Vite as build tool
- TailwindCSS for styling
- React Query for state management
- React DnD for drag-and-drop
- date-fns for date handling
</frontend>

<testing>
- Vitest for unit tests
- React Testing Library for component tests
- Playwright for E2E tests
- MSW (Mock Service Worker) for API mocking
</testing>

<ci_cd>
- GitHub Actions for CI/CD
- Vercel/Netlify for deployment
- Automated testing on PR
- Preview deployments for branches
</ci_cd>
</technology_stack>

<features>
<core_features>
1. Task CRUD operations
2. Task categorization with tags
3. Priority levels (Low, Medium, High, Critical)
4. Due date assignment with reminders
5. Drag-and-drop task reordering
6. Search and filter functionality
7. Dark/Light theme toggle
8. Keyboard shortcuts
9. Responsive mobile design
10. Local storage persistence
</core_features>

<optional_features>

</features>
